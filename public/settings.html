Тема

VS Code — тёмная схема Dark+: нейтральный серый и её акцентный синий.

Шрифт интерфейса

Segoe UI — тот же шрифт, которым набран интерфейс VS Code на Windows. Данные (порты, hex, лог) всегда остаются моноширинным Consolas.

Окно

Без неё заголовок приложения сам работает шапкой окна: за него оно таскается, а кнопки свернуть, развернуть и закрыть встроены справа.
